About

I'm a software engineer who likes the part of the job that happens after the code is written: building, testing, releasing and watching it run. I care about pipelines that tell you the truth and rollbacks that happen before anyone files a ticket.

I work across Python and Go services, container platforms and a little machine learning where it earns its place. I write tests first when the problem is unclear and last when it is obvious.
